# IronNote

Личный дневник силовых тренировок. Записывайте подходы, смотрите историю и прогресс.
Приложение не составляет программы, не даёт советов и не анализирует вас — оно хранит
фактические данные и считает по ним статистику.

Работает в браузере, mobile-first (от 320 px), тёмная тема.

## Что умеет

- **Справочники** — группы мышц (10 предзаполнены) и упражнения с привязкой к
  нескольким группам мышц и одной основной.
- **Шаблоны тренировок** — упорядоченный список упражнений с планируемыми
  подходами, повторениями и весом. Шаблон — заготовка, а не история.
- **Тренировка** — с нуля или по шаблону, подходы с весом и повторениями,
  тёплые подходы, заметки, копирование подхода в один тап, изменение порядка
  упражнений, завершение и последующее редактирование.
- **История** — завершённые тренировки в обратном порядке, фильтр по датам,
  длительность, число упражнений и подходов, тренировочный объём.
- **Статистика** — тренировки и объём за период, разбивка по месяцам, рекорды по
  каждому упражнению, графики объёма и расчётного 1ПМ (формула Эпли).

Незавершённая тренировка хранится в PostgreSQL: после перезагрузки страницы её
можно продолжить с того же места.

## Стек

| Слой | Технологии |
|---|---|
| Frontend | React 18, TypeScript, Vite, Tailwind CSS, React Router, TanStack Query, Recharts |
| Backend | Go, chi, pgx/v5, sqlc, встроенные SQL-миграции |

| Инфраструктура | Docker Compose: `frontend`, `backend`, `postgres` |

## Быстрый старт (Docker Compose)

Нужен только Docker с плагином Compose.

```bash
cp .env.example .env
# откройте .env и задайте POSTGRES_PASSWORD
docker compose up --build
```

Откройте <http://localhost:8080>. Миграции применяются автоматически при старте
backend, справочник групп мышц заполняется seed-миграцией.

Остановить, сохранив данные: `docker compose down`.
Остановить и **удалить базу**: `docker compose down -v` (необратимо).

## Проверка работоспособности

```bash
curl http://localhost:8080/api/muscle-groups      # 10 групп мышц
curl http://localhost:8080/healthz-api            # {"status":"ok"}
```

Или в интерфейсе: **Тренировки → Начать → + Упражнение → + Подход**, введите вес
и повторения, **Завершить**. Тренировка появится в «Истории» и в «Статистике».

## Запуск без Docker (разработка)

Нужны Go 1.23+, Node 20+ и PostgreSQL 14+.

```bash
# 1. База
createdb ironnote

# 2. Backend
cd backend
export DATABASE_URL="postgres://$(whoami)@localhost:5432/ironnote?sslmode=disable"
export APP_TIMEZONE=Europe/Moscow
go run ./cmd/api            # :8080, миграции применяются сами

# 3. Frontend (второй терминал)
cd frontend
npm ci
npm run dev                 # :5173, /api проксируется на :8080
```

Откройте <http://localhost:5173>.

## Тесты

```bash
make test                       # backend + frontend

cd backend && go test ./...     # юнит-тесты правил + интеграционные
cd frontend && npm run test     # компоненты и форматирование
```

Интеграционные тесты backend работают с настоящим PostgreSQL и создают для каждого
теста отдельную временную базу. Без `TEST_DATABASE_URL` они пропускаются, а не
падают:

```bash
cd backend
TEST_DATABASE_URL="postgres://user@localhost:5432/postgres?sslmode=disable" go test ./...
```

Юнит-тесты статистики (`internal/service/stats_test.go`) проверяют объём,
исключение разминочных подходов, формулу Эпли и то, что фактический 1ПМ не
смешивается с расчётным.

## Переменные окружения

Все переменные описаны в `.env.example`; значения в репозитории не хранятся.

| Переменная | Обязательна | По умолчанию | Назначение |
|---|---|---|---|
| `POSTGRES_PASSWORD` | да | — | пароль роли PostgreSQL |
| `POSTGRES_USER` | нет | `ironnote` | пользователь БД |
| `POSTGRES_DB` | нет | `ironnote` | имя базы |
| `APP_PORT` | нет | `8080` | порт веб-интерфейса на хосте |
| `APP_TIMEZONE` | нет | `Europe/Moscow` | часовой пояс для разбивки по месяцам |
| `LOG_LEVEL` | нет | `info` | `debug` / `info` / `warn` / `error` |
| `DATABASE_URL` | да (backend) | — | строка подключения pgx |
| `HTTP_ADDR` | нет | `:8080` | адрес прослушивания API |
| `CORS_ALLOWED_ORIGINS` | нет | пусто | нужно только при отдельном фронтенде |

## Решения, о которых стоит знать

- **Одна незавершённая тренировка.** Вторую начать нельзя (409): иначе «продолжить»
  становится двусмысленным, а данные теряются.
- **Удаление с защитой истории.** Упражнение, использованное в тренировке или
  шаблоне, удалить нельзя — предлагается архив. Удаление шаблона не меняет
  завершённые тренировки: при старте упражнения и подходы копируются в сессию.
- **Веса — `NUMERIC`, не `FLOAT`.** 1.25 кг остаётся 1.25 кг во всех суммах.
- **Один источник расчётов.** История и статистика считаются из одних и тех же
  строк одними и теми же функциями, поэтому не могут разойтись.
- **Без авторизации.** Приложение для одного человека в доверенной среде; доступ к
  данным отделён от бизнес-логики, чтобы позже добавить пользователей.
